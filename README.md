# Thor RPG (AYN Thor)

듀얼스크린 Android RPG 실험 프로젝트.

## 현재 상태
- Android WebView 기반 초기 프로토타입 v0.4를 업로드할 예정입니다.
- 기본 직업: 전사, 마법사, 궁수, 암살자.
- 히든 직업 방패술사/흑기사는 임시 버전에서 미구현.

## APK 빌드
Android 프로젝트 파일이 업로드된 뒤 GitHub Actions의 **Build Android APK** 워크플로에서 `app-debug.apk`를 생성합니다.

현재 저장소에 Android 앱 소스가 없으면 빌드는 성공할 수 없습니다.
